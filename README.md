# ControlPrestamos Cliente

Web informativa de la aplicación Android: presentación, política de privacidad y condiciones de uso.

El repositorio contiene únicamente páginas públicas y estilos. No contiene registros financieros ni credenciales.

Publicación prevista: GitHub Pages desde la rama main y la carpeta raíz.
Dominio configurado en CNAME: controlprestamoscliente.duckdns.org.

La configuración DNS, HTTPS y verificación OAuth se comprueban por separado; la presencia de los archivos no acredita que estén completadas.
