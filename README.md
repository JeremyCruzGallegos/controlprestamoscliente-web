# ControlPrestamos Cliente

Web informativa de la aplicación Android: presentación, política de privacidad y condiciones de uso.

El repositorio contiene únicamente páginas públicas y estilos. No contiene registros financieros ni credenciales.

## Publicación

GitHub Pages debe usar la rama `main` y la carpeta raíz `/(root)`. El archivo `index.html` y `CNAME` están en esa raíz.

Dominio configurado: `controlprestamoscliente.duckdns.org`.

Rutas de la web:

- Inicio: https://controlprestamoscliente.duckdns.org/
- Privacidad: https://controlprestamoscliente.duckdns.org/privacidad/
- Condiciones: https://controlprestamoscliente.duckdns.org/condiciones/

Antes de utilizar estos enlaces en Google Cloud, comprobar que el último despliegue de Pages termine correctamente y que las tres páginas abran por HTTPS. La presencia de los archivos y la validación DNS no acreditan que el despliegue haya terminado.
